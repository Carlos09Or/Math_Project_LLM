T3 y T4 · Ajuste del formato del prompt

Para calificar automáticamente si el modelo resolvió bien un problema, el corrector busca al final una línea Respuesta final: …. Si el modelo la escribe de otra manera, no se puede leer. Aquí se probó cómo pedir ese formato.

Esto ajusta la indicación al modelo, no el dataset. Los problemas que se usaron son de práctica, aparte del dataset, para no ajustar el prompt a los ítems reales. Solo se cambió la instrucción de «resolver»; los prompts de diagnosticar y de pista nunca se ajustaron.

Las reglas, fijadas antes de correr

  1. Se elige solo por legibilidad del formato, nunca por exactitud.
  2. Una variante se da por buena solo si el corrector lee ≥ 90 % de las respuestas en total y ≥ 80 % en las divisiones.
  3. Si dos empatan (3 puntos o menos), gana la instrucción más corta.
  4. Si ninguna cumple, no se congela ninguna y no se relaja el umbral.

El prompt congelado para la evaluación

Una prueba automática falla si cambia una sola letra de estos textos. Cambiarlos después de ver resultados del piloto exige una versión nueva y reportar ambas.

Lo que conviene tener claro

  • El formato afecta lo que se mide. Las variantes dan «exactitud aparente» distinta sobre todo porque lo ilegible cuenta como fallo; por eso el formato se fija antes de evaluar.
  • La variante elegida tuvo la exactitud aparente más baja de las cuatro. No cambia la decisión (la regla era por legibilidad), pero se dice abiertamente.
  • Se probó con un solo modelo y 12 problemas por ronda: al añadir otras familias hay que repetir esta comprobación.
  • Pedir «cociente y residuo» le dice al modelo que es una división. Afecta a todas las variantes por igual y está anotado como decisión pendiente del mentor (D-08).
