MathTutorBench

Benchmark de Macina et al. (EMNLP 2025). Lo usamos como referencia de método (qué habilidades de tutoría medir), no como datos: sus datos fuente están en inglés y son de nivel de primaria superior o secundaria.

  • Licencia sin resolver: el repositorio no tiene archivo LICENSE y la API de GitHub no devuelve licencia; el README y el sitio mencionan CC BY-SA 4.0 y CC BY 4.0. No se copian datos ni código hasta aclararlo. VERIFICADO
  • El modelo de recompensa de pedagogía se entrenó y validó en inglés; no hay evidencia de que funcione en español de 3.er grado. PARCIAL
  • Referencias de la propuesta aún sin verificar: Lu 2025, Zhou 2025, Zhang 2026 y MRBench (Maurya 2025). PENDIENTE
